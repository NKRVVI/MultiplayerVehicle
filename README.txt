Objective
Create a 2–4 player peer-to-peer multiplayer vehicle prototype in Unreal Engine 5.4+.

Requirements
Implement a P2P multiplayer session where one player acts as the host.
Multiple players should be able to join the same session and control their own vehicles.
Implement vehicle:
Steering
Throttle
Brake
Reverse
Gear shifting
Synchronize vehicle movement and state between all connected players.
Implement basic vehicle-to-vehicle collision and damage.
Implement enter/exit vehicle functionality.
An occupied vehicle must not be possessable or controllable by another player.
Handle player joining and leaving the session properly.
Test the system under latency and packet-loss conditions.
